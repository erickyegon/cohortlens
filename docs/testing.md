# Testing

- `make test`: pytest unit + integration (Testcontainers, Postgres 16), telemetry leak test, Vitest, agent replay tests.
- `make e2e`: Playwright against Compose (separate CI job).
- `make verify-seed`: load the committed seed into a throwaway Postgres 16 container and assert the reference cohort (920 → 481).
- Quality gates: 80% line coverage on `api/app/cohort_engine/`; Ruff + ESLint clean; no real Anthropic API calls.
- Dev dependencies: `pip install -r api/requirements-dev.txt` (Docker required for Testcontainers).

## Truth fixture

`api/tests/fixtures/truth_fixture.sql` holds 20 hand-built patients (generated by `api/tests/fixtures/build_truth_fixture.py`; edit the generator, not the SQL). Every patient exists to exercise one criterion or boundary of the reference cohort in `docs/spec.md` §7. The expected counts below were worked out by hand before any code ran; `api/tests/integration/test_truth_fixture.py` asserts them against `data/etl/example_cohort.sql`, the oracle the cohort engine must reproduce.

Reference cohort attrition on the fixture: **19 → 17 → 15 → 12 → 10 → 9**.

| Step | Count | Removed here (and why) |
|---|---|---|
| First lisinopril exposure (index) | 19 | P4: enalapril only, never lisinopril |
| ≥365 days prior observation | 17 | P5: 112 days of observation · P7: 364 days (P6 has exactly 365 and stays in) |
| No ACE inhibitor in prior 365 days | 15 | P8: enalapril 100 days before · P10: enalapril exactly 365 days before (P9 had it 401 days before and stays in) |
| Hypertension on or before index | 12 | P11: none · P12: diagnosed the day after index · P19: hypertension only after the *first* lisinopril (tests first-occurrence index); P13 has it on the index date and stays in |
| No prior heart failure | 10 | P14: heart failure before index · P16: chronic CHF, a descendant concept (P15 has it only after index and stays in) |
| Age ≥ 50 at index | **9** | P17: 49, turns 50 the day after index (P18 turns 50 exactly on the index date and stays in) |

Final cohort: P1, P2, P3, P6, P9, P13, P15, P18, P20.

Criterion types and the patients that cover them:

| Criterion type | Patients |
|---|---|
| Descendant expansion, drug (ingredient → clinical drug, combination product) | P1, P2 (20 mg), P3 (hydrochlorothiazide combination) |
| Descendant expansion, condition (hypertension child; heart failure child) | P2, P16 |
| First-occurrence index | P19 |
| Observation window boundary (365 vs 364 days) | P6, P7 |
| Washout window boundary (365 vs 401 days) | P9, P10 |
| Same-day event (`≤ index`) | P13 |
| Event after index must not count | P12, P15 |
| Age boundary (birthday on / one day after index) | P17, P18 |
| Death after index does not remove a patient | P20 |

Rules for extending the fixture: add a patient and a row in the table above in the same change, regenerate the SQL, and update the expected numbers in the test. Never derive an expected number by running the code under test.
